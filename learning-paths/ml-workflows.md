# Improve ML Workflows

AI and automation can reduce repeated work during model development. The goal of this path is to use them without weakening how we run and compare the experiment.

## 1. Establish automated baselines

Let's select two resources from [AI-Assisted Machine Learning](../resources/ai-assisted-machine-learning.md). Run them with one fixed split and metric so we can compare the result fairly.

## 2. Test a tabular foundation model

If the problem uses tabular data, choose a model from [Tabular Foundation Models](../resources/tabular-foundation-models.md). Compare it with a tuned tree ensemble and a simple baseline.

## 3. Delegate repetitive engineering

Next, use a resource from [Coding Agents and Context Engineering](../resources/coding-agents-and-context.md) to turn repeated preprocessing, training, and reporting code into tested functions.

## 4. Make experiments reproducible

Lastly, apply [MLOps and Production](../resources/mlops-and-production.md) so we can track the parameters, code versions, metrics, and artifacts.

**Capstone:** a reproducible benchmark report that compares at least three approaches. We should be able to regenerate the report with one documented command.

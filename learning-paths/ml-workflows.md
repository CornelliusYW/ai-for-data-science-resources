# Improve ML Workflows

**Goal:** use AI and automation to improve our model development without weakening the experiment.

## 1. Establish automated baselines

Select two resources from [AI-Assisted Machine Learning](../resources/ai-assisted-machine-learning.md). We can run them with one fixed split and metric to create a fair comparison.

## 2. Test a tabular foundation model

If our problem is tabular, choose a model from [Tabular Foundation Models](../resources/tabular-foundation-models.md). Compare it with a tuned tree ensemble and a simple baseline.

## 3. Delegate repetitive engineering

Use a resource from [Coding Agents and Context Engineering](../resources/coding-agents-and-context.md) to turn repeated preprocessing, training, and reporting code into tested functions.

## 4. Make experiments reproducible

Apply [MLOps and Production](../resources/mlops-and-production.md) so we can track the parameters, code versions, metrics, and artifacts.

**Capstone:** a reproducible benchmark report that compares at least three approaches. We should be able to regenerate the report with one documented command.
